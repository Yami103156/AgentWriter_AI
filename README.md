# AgentWriter_AI

## 🚀 Quick Start
 1. Clone the repository

```bash
git clone https://github.com/Yami103156/AgentWriter_AI
cd AgentWriter_AI
```
 2. Create and activate a virtual environment

```bash
conda create  -n agentwriter python=3.11 -y
```
 3. Activate virtual environment

 ```bash
conda activate agentwriter
```
4.  Install requirements.txt

```bash
pip install -r requirements.txt
```
5. Run Application

```bash
python app.py
```
